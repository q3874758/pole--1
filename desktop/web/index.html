游戏防打扰保障声明 (Anti-Disturbance)

绝对零弹窗、零焦点抢占

启动和运行全程绝不弹出任何浏览器或黑框，不抢夺鼠标键盘焦点，保障游戏 100% 全屏独占与流畅。

⚡

后台进程绑定 Windows `IDLE_PRIORITY_CLASS` 与能效核心，物理内存压制在 15MB 内，绝不导致游戏掉帧。
